# Задачи плагинов Lampa Downloader

Рабочий список при коде. Крупные вехи — в `personal-hub/lampa-downloader/GOALS.md`,
durable-выводы и грабли — в файлах памяти.

Обозначения: `[ ]` не начата · `[~]` в работе · `[x]` готово И ПРОВЕРЕНО.
У готовой задачи приписано, **чем** проверял.

**Не путать с плагином BWA** (`bwa_online`, домен `rust.bwa.ad`) — это
отдельный видео-плагин Лампы и отдельный проект. Здесь только кнопка
«Скачать на ПК».

## Открытое

- [~] **console_plus.js — улучшенная консоль разработчика (отдельный плагин).** v0.1.
      База — рабочий `console-plus.js` (подменяет штатную консоль `Настройки → Остальное
      → Консоль`): категории слева, вкладка «Запросы» с кодом и скоростью ответа, детали
      в Modal, навигация пультом/пальцем. Поверх добавлено по просьбе Сергея: (1) строка-
      диагноз сверху «Запросов» — самый медленный запрос, медиана, число ошибок, сколько
      висит; (2) переключатель сортировки запросов «по времени / по скорости» (пилюля,
      фокус пультом); (3) показ ВИСЯЩИХ запросов (pending) живьём со счётчиком «висит Nс» —
      чтобы ловить зависший запрос, который в список завершённых не попадает. Там же обе
      правки по замечаниям Ягами: убрана зебра (каждая вторая строка не приглушается) и
      авто-обновление не сбивает фокус пульта (ревью: `cur===last_count`, `index<=0`).
      СДЕЛАНО/ПРОВЕРЕНО: `node --check` ок; логика pending/диагноза/сортировки прогнана
      отдельным тестом (pending 3→0, медленный/медиана/ошибки, сортировка, фильтр — всё
      сошлось). ОСТАЛОСЬ: прогон в реальном браузере/на ТВ (стенд `bwa-rust/tools/lampa-e2e`
      или живой телевизор) — UI и навигацию пультом в реальной Лампе ещё не гонял.
      Ставится по URL `raw.githubusercontent.com/apk-storage/lampa-plugins/main/console_plus.js`.

## Сделано

- [x] **legal_ru_online v1.1.0: убит вечный `setInterval(50мс)`, удалён дубль v2.**
      Перестановка рядов главной была 20 раз/сек бесконечно (скан DOM) — тормозило слабые
      ТВ. Стало событийно: при входе на главную (`Listener` на `app ready` и `activity`
      component=main) короткий дозор 300мс, максимум ~6 c, сам выключается, как только оба
      ряда встали (`promoteMainRows` возвращает признак стабильности). Удалён
      `legal_ru_online_v2.js` (глобально патчил `tmdb.get` + вечный MutationObserver — хуже
      по архитектуре), снят мёртвый `allTmdbPatched`. Проверено: `node --check` ок, логику
      дозора прошёл глазами. ОСТАЛОСЬ: прогон на реальной главной (ряды должны вставать
      первыми и дозор гаснуть) — на ТВ не гонял. Если cub/каталог ссылался на `_v2` — его
      надо переназначить на `legal_ru_online.js`.

- [x] **studios_ru: баг отрисовки карточек + 9 пунктов меню сведены к одному.**
